Cara pasang:
1. Extract ZIP langsung ke folder Lab7Web-2.
2. Pilih Replace jika diminta.
3. Jalankan backend: php spark serve
4. Buka frontend: http://localhost/lab11_ci/Lab7Web-2/lab8_vuejs/#/
5. Coba buka menu Kelola Artikel tanpa login. Sistem harus mengarahkan ke Login.
6. Login memakai akun user database. Akun bawaan lokal biasanya ID 1 atau username admin dengan password 1.
7. Setelah login, coba tambah/ubah/hapus artikel dari VueJS.
8. Untuk Praktikum 14, uji POST /post dari Postman tanpa Authorization header. Response harus 401 Unauthorized.
